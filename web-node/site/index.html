با هزینه‌ای که می‌فهمید.

TakRouter یک درگاه سازگار با OpenAI است که با روش UniRoute برای هر پیام مدل مناسب را انتخاب می‌کند و کش معنایی، بررسی کیفیت، تشدید و جایگزینی خودکار را هم انجام می‌دهد.

امتحان کنید نتایج آزمون

مسیر هر درخواست

هفت مرحله، با سربار p95 حدود ۷۲ میلی‌ثانیه بدون زمان خود مدل.

قلب مسیریاب: UniRoute

پیام‌ها خوشه‌بندی می‌شوند و هر مدل برای هر خوشه یک «اثر انگشت» نرخ خطا دارد. امتیاز هر مدل این است: s(h) = Ψk(h) + λ·ĉ(h). افزودن مدل تازه فقط یک ردیف به این جدول اضافه می‌کند.

نتایج روی داده آزمون مهرشده

محور افقی لگاریتمی است. خطوط، بازه اطمینان ۹۵٪ هستند.

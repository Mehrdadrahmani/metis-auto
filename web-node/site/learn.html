اولین گفتگوYour first chat

در این آموزش یک پیام می‌فرستید و یاد می‌گیرید خط زیر هر پاسخ چه می‌گوید.

You send one message and learn what the line under each answer tells you.

  1. وارد شویدSign in از دکمه‌ی «ورود» بالای صفحه وارد شوید یا حساب بسازید.Use "Sign in" at the top, or create an account.
  2. پیام بنویسیدWrite a message به صفحه‌ی «گفتگو» بروید، پیام را بنویسید و Enter بزنید. برای خط جدید Shift+Enter.Open Chat, type your message and press Enter. Shift+Enter makes a new line.
  3. خط زیر پاسخ را بخوانیدRead the line under the answer مدلی که جواب داد، هزینه، زمان و صرفه‌جویی نسبت به Claude Sonnet.The model that answered, the cost, the time and the saving against Claude Sonnet.
    GPT-5.6 Luna$0.0003۴٫۵ ثانیه4.5 s۸۸٪ ارزان‌تر از Claude Sonnet88% cheaper than Claude Sonnet
  4. کپی، تکرار یا بهترین کیفیتCopy, regenerate or best quality زیر هر پاسخ می‌توانید آن را کپی کنید، دوباره بگیرید، یا با «بهترین کیفیت» دوباره بپرسید.Under each answer you can copy it, regenerate it, or ask again with "Best quality".

صرفه‌جویی: اقتصادی، متعادل، بهترین کیفیتSave money: Economy, Balanced, Best quality

پیام‌های ساده، حجم زیادSimple messages, high volumeبیشتر به ارزان‌ترین مدل‌ها می‌رودMostly the cheapest models
بیشتر کارها (پیشنهادی)Most work (recommended)کیفیت هم‌سطح Sonnet با حدود ۴٪ قیمتSonnet-level quality at about 4% of the price
سؤال مهم یا دشوارImportant or hard questionsدر هر موضوع بهترین مدل، هر قیمتی داشته باشدThe best model of each topic, whatever it costs
برای کنترل دقیق‌تر، دکمه‌ی تنظیمات کنار حالت‌ها نواری دارد که هر نقطه‌اش یک تغییر واقعی در انتخاب مدل است.For finer control, the settings button next to the modes opens a slider; every stop on it is a real change in model choice.

«چرا این مدل؟» و مسیر تصمیم"Why this model?" and the decision trace

زیر هر پاسخ دکمه‌ی «چرا این مدل؟» موضوعی را که TakRouter تشخیص داد و کیفیت هر مدل در همان موضوع را نشان می‌دهد. کیفیت یعنی سهم پاسخ‌هایی که داور ما در ۷۹۸ پرسش آزمون قبول کرد.

Under each answer, "Why this model?" shows the topic TakRouter detected and each model's quality on it: the share of answers our judge passed on 798 evaluation questions.

  1. مسیر تصمیم را روشن کنیدTurn on the decision trace کلید «نمایش مسیر تصمیم» بالای صفحه‌ی گفتگو. انتخاب شما ذخیره می‌شود.The "Show decision trace" switch at the top of Chat. Your choice is saved.
  2. مراحل را بخوانیدRead the steps مدل‌های مجاز → درک پیام → حافظه (کش) → منابع (RAG) → انتخاب مدل با امتیاز هر مدل → فراخوانی → بررسی پاسخ → جمع هزینه و زمان.Allowed models → understanding → cache → retrieved context (RAG) → model choice with every score → call → answer checks → total cost and time.
  3. امتیاز را بفهمیدUnderstand the score امتیاز = نرخ رد در این موضوع + λ × قیمت نسبی. کمترین امتیاز برنده است. حالت‌ها فقط λ را عوض می‌کنند.Score = fail rate on this topic + λ × relative price. The lowest score wins. The modes only change λ.

دستیار کسب‌وکار خود را بسازیدBuild your business assistant

با «دستور سیستمی» به دستیار شخصیت و قانون می‌دهید. در گفتگو: تنظیمات ← «دستور سیستمی».

A system prompt gives the assistant a persona and rules. In Chat: settings → "System prompt".

نمونه: پشتیبانی فروشگاهExample: shop support
«تو دستیار پشتیبانی فروشگاه کتاب‌آنلاین هستی. کوتاه، مودبانه و فارسی جواب بده. اگر سؤال درباره‌ی سفارش است، شماره‌ی سفارش را بپرس. درباره‌ی موضوعات دیگر صحبت نکن.» "You are the support assistant of an online bookshop. Answer briefly and politely. If the question is about an order, ask for the order number. Do not discuss other topics."
  1. نقش را بگوییدSay the role«تو ... هستی»."You are …".
  2. لحن و طول را مشخص کنیدSet tone and length«کوتاه»، «رسمی»، «با فهرست»."Brief", "formal", "use lists".
  3. مرزها را بگذاریدSet the limitsچه کاری نکند، و وقتی نمی‌داند چه بگوید.What it must not do, and what to say when it does not know.
مسیریابی بر اساس پیام کاربر است، نه دستور سیستمی؛ پس هر پیام همچنان به مدل مناسب خودش می‌رود.Routing uses the user's message, not the system prompt, so each message still goes to its own best model.

ربات خود را در ۵ دقیقه وصل کنیدConnect your chatbot in 5 minutes

  1. کلید API بسازیدCreate an API keyحساب کاربری ← کلیدهای API ← «کلید تازه». کلید فقط یک بار نشان داده می‌شود.Account → API keys → "New key". The key is shown only once.
  2. آدرس را عوض کنیدChange the addressهر کتابخانه‌ی OpenAI کار می‌کند؛ فقط آدرس پایه و نام مدل را عوض کنید.Any OpenAI library works; change only the base URL and the model name.
from openai import OpenAI

client = OpenAI(base_url="/v1", api_key="tk-...")
reply = client.chat.completions.create(
    model="takrouter",
    messages=[{"role": "user", "content": "سلام"}],
    extra_body={"metadata": {"lambda": 0.515}},   # optional
)
print(reply.choices[0].message.content)
print(reply.model)  # the model TakRouter chose

const r = await fetch("/v1/chat/completions", {
  method: "POST",
  headers: {"Content-Type": "application/json", "Authorization": "Bearer tk-..."},
  body: JSON.stringify({model: "takrouter", messages: [{role: "user", content: "سلام"}]}),
});
const data = await r.json();
console.log(data.choices[0].message.content, data.takrouter);

اجرای TakRouter روی سرور خودتانRun TakRouter on your own server

  1. نصبInstall
    uv sync
uv run python scripts/fetch_model.py   # the routing embedder, once
  2. کلید MetisMetis keyدر فایل .env مقدار METIS_BASE_URL و METIS_API_KEY را بگذارید. این فایل هرگز در git نمی‌رود.Put METIS_BASE_URL and METIS_API_KEY in .env. That file never goes into git.
  3. سقف هزینهSpending limitدر configs/budget.yaml مقدار product سقف کل وب‌سایت است.In configs/budget.yaml, product is the whole site's limit.
  4. اجراRun
    TAKROUTER_PROVIDER=live uv run uvicorn metis.gateway.app:app --port 8000
    اولین حسابی که ثبت‌نام کند، مدیر است.The first account to sign up is the administrator.

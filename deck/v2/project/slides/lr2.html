L1 · The request path

Eight steps, and only two of them can call a model

1

Receive

Text, last two turns, files

2

Feature card

By code, no model call

3

Hard filter

Drop models that cannot serve it

4

Cache + RAG

A hit is the answer, else evidence

5

Decide

Rule, or the LLM router

6

Call

Backup on another provider

7

Check

Rules only, no judge call

8

Log

Cost, reason, saving

Purple steps are the only ones that can call a model

Cache hit goes straight to the log

Provider error runs the backup

A bad answer is retried once, stronger

Eight nodes of a LangGraph state machine, and the state is the trace of the request. Step two is the one to notice: the feature card is built by code, with regular expressions and counting, so it is exact and free. That is the answer to the obvious objection, that we call a model in order to choose a model. Step seven is the same story: the answer check is rules only, empty, cut off, a refusal, or not Persian. The model judge belongs to the evaluation path, not to every request. Only steps five and six can call a model, and step five calls one for about a tenth of the traffic.

Part 2 is free: a multilingual embedding model turns each unlabeled prompt into a vector, and K-means groups them into topics, only from user text. Part 3 is the only paid part: all four models answer the 800 validation prompts and a judge scores each answer; seven or more is a pass. From this we get the fingerprint, psi: for each model, its average error in each topic. That small table is the router's knowledge.

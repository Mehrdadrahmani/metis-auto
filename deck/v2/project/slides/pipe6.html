T2.4 · Part 6

Route each new message, online

1 · Embed

the message and 2 previous turns

2 · Nearest topic

closest of the 8 centres

3 · Score

error in that topic + λ × cost

4 · Route

lowest score; if it fails, the next

Part 6 runs for every message, in milliseconds. Embed the message with its two previous turns, find the nearest topic centre, score each model by its error in that topic plus lambda times its cost, and send the message to the lowest score. If that provider fails, the next lowest answers. This is what the website and the API do on every request.

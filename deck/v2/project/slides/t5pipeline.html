T5 · The pipeline

From real prompts to a router, in five steps

Blue is free and offline, orange is the only paid step, green is online. The test set is never used for any choice.

Full diagram with every step: backup slide “Full pipeline”

The whole method in five steps. We prepare 338 thousand real prompts and split them into a large unlabeled train part, 800 validation and 300 sealed test prompts. We learn 8 topics from user text only. The only paid step: four models answer the 800 validation prompts and a judge scores them. From that we build the score table, each model's error per topic, and choose K and lambda on validation. Online, every message is routed with cache and failover.

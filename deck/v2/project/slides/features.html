What makes TakRouter different, in four points. First, it is learned once, from good data: from real questions, we learn the topics and how well every model does on each topic, checked by a judge. Second, when a new model comes out, it only has to answer our validation questions once to get its scores, and then the router can use it. Nothing is retrained. Third, every message goes to the best quality for the price across all the providers we connect, not just one company's models. Fourth, it never gets stuck: if a provider fails, the next model answers, and repeated questions come straight from the cache.

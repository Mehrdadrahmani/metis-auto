Our evidence. We froze the router, then opened a sealed test set once: 299 real Persian chatbot messages. TakRouter cost 96% less than always using Claude Sonnet, and quality was not lower; the interval includes zero, so we claim equal, not better. In a simulated ten-minute outage of the main provider, no request failed. On the Khayyam exam benchmark with true answers, the best model changes by subject and routing beat the best single model. Honest note: on easy chatbot traffic, always using DeepSeek is as good; the gain grows with harder, more varied traffic. That is why our ask is about data.

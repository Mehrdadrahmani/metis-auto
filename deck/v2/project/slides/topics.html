Our solution

We send each question to the best-value model for its topic

This is the core idea in one picture. Messages that mean similar things land close together, so they form groups, which we call topics. We learned 8 topics from real user messages, with no labels; here are four of them. For each topic we measured which model gives the best quality for its price. In most topics that is DeepSeek, but for humanities and religion it is GPT-5.6 Luna. When a new message arrives, we see which topic it falls into, and send it to that topic's best-value model. Here a health question goes to DeepSeek. Sources: [7] TakRouter validation, n = 798 (4 of 8 topics shown; model picks from validation).

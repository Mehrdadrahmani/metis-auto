Human in the loop

Human labels and a feedback loop from day one.

The hard question investors ask: what if the model does not work? If a provider goes down, the next model answers; in a simulated ten-minute outage no request failed. If an answer looks weak, a check sends it to a stronger model; that happened for 0.3 percent of messages. We know our error range: compared with always using Sonnet, the pass rate was 2 points higher, with a 95 percent range from minus 3 to plus 7. And human labels plus a feedback loop improve the router from day one. Source: [4] our sealed test.

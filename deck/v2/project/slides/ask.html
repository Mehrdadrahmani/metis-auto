The ask

Help us prove routing on richer data

1 · Cleaner, more varied data

Chatbot traffic with topic labels, harder tasks and true answers, so messages can be classified easily and the router can learn where models differ.

2 · Resources to build the product

Servers in Iran, model credits for evaluation, human labelers, and 3–5 pilot partners.

Why it matters: on easy chatbot data the cheapest good model wins almost everywhere; on varied exam data routing shows a real gain [2].

[2] Our Khayyam benchmark, n = 1,100, true answers: +0.020 area (95% CI +0.001 to +0.044)

Our ask is not money today. First, data: cleaner and more varied traffic with topic labels and known answers. On our chatbot data the questions were easy and similar, so one cheap model won almost everywhere; on the Khayyam exam set, where subjects differ, routing showed a real gain. Better data lets us show the value clearly. Second, resources to build the product: servers in Iran, model credits for evaluation, human labelers, and a few pilot partners. With these, the next milestone is a live service with measured gains for real customers.

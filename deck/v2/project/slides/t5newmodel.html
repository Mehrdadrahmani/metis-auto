T5 · Adding a model

A new model joins in one step, no retraining

Holdout check: adding Gemini from its validation row moved the test area from 0.680 to 0.686.

[1] Sealed test, holdout demo (results/holdout_demo.md)

Adding a model does not need retraining. The new model answers the validation prompts once, we compute its error per topic, and it becomes one new row in the table. We tested this by holding Gemini out and adding it back from its row only; the result improved slightly.

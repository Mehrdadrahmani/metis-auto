Base models are available to everyone, so why bet on us? First, our data: a Persian test set built from real questions with judged answers, so every model has a score on every topic; nobody else has it. Second, a feedback loop: more traffic gives better topics and better scores, so better choices. Third, speed: a new model only has to answer our test questions once to be added, no retraining, so we can add it the day it comes out. Fourth, switching: joining is a one-line change, but history, saved costs and rial billing make customers stay.

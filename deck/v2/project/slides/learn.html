How it learns

Every model answers, a judge scores, we learn who is best where

The main idea of how TakRouter learns. We start from a lot of real chat sessions: rich data, 710,640 messages from 1,830 Persian chatbots. We pick candidate models, here DeepSeek, GPT, Gemini and Claude, and each one answers the same questions. Then an LLM judge, Jev, scores every answer from 1 to 10; 7 or more is a pass. Because the questions are grouped into topics, we now know how good each model is in each topic: a scorecard. Each topic can have a different winner; the real results come later in the talk. When a new model appears, it just answers the same questions and gets its own column.

What actually reaches the router: “the cheap model answered 14 times, 3 were referred to an agent”

Two stages. Offline, once: the past turns are cleaned, each gets a sample card holding which model answered, what it cost and how it ended, the user text is embedded with Jina v5 nano, and k-means builds a bank of 40 clusters. Online, per request: embed, take the one to three clusters whose centre is at least zero point seven five similar, pull the ten nearest members of each, drop near duplicates, and summarise per model how often it answered and how often that went wrong. Failure means referred to an agent, a complaint, or the user asking again. If a judge asks whether this is GraphRAG, the answer is no. There is no knowledge graph. LangGraph in this project orchestrates the steps; it is not a retrieval graph.

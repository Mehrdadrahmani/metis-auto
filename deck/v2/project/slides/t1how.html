How the router chooses, in four steps. It turns the message into a vector, finds the nearest of eight topic centres, looks up each model's error on that topic, and picks the model with the lowest error plus lambda times cost. Lambda sets the balance; we chose 0.515 on validation. The topics come from user text only; the score table comes from 800 validation prompts judged by an AI judge. This is UniRoute, from Google, published at ICLR 2026.

T1 · The clustering idea

Topics are learned from meaning, with no labels

209,109 unlabeled train prompts

Jina v5 nano embeddings, user text only

K-means, K = 8

Vectors stored in Qdrant

Topic sizes on validation: 58 to 187 prompts

Step one of UniRoute. We embed only the user’s own text, not the chatbot’s system prompt, so topics reflect what people ask. The embedding model is jina-embeddings-v5-text-nano, run locally, and all vectors are kept in a Qdrant vector database. K-means groups 209,109 unlabeled train prompts into 8 topics; the names were given afterwards by reading the clusters. On validation the topics hold between 58 and 187 prompts: General short chat 187, Short fragments 113, Account and tech support 106, Science and maths 105, Relationships 86, Humanities 78, Health 65, Payments 58. The K-selection rule on validation preferred K = 4; we shipped K = 8 and report K = 4 results too.

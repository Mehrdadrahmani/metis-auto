This is our biggest technical advantage. Other routers often need retraining when a model changes. With UniRoute, a new model only answers our 800 validation questions once, the judge scores them, and its error rate in every topic becomes one new column. The topics and everything else stay the same. We tested this: we hid Gemini, then added it back using only its validation answers, and the router improved without retraining. The website already has an admin flow to add a model this way.

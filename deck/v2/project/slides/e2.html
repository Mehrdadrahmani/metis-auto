Metis routing · Golden Set, 100 samples · 3 Nov 2026

How we evaluated. Real data: the Golden Set, 100 conversations sampled from production across four products. Same pipeline: two live Metis servers, identical except one flag, with separate caches. Blind scoring: an LLM judge scores every answer on correctness, instruction following, completeness, relevance and format, without knowing which system wrote it. Paired results: both systems answer the same question, and production answers are the reference bar. The only difference: the LLM router makes an extra LLM call to pick the model; TakRouter embeds the request, finds the nearest cluster and picks the model with the best success for its cost.
